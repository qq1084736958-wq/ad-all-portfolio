# 全局警戒规则（最多 10 条）
> 每次启动必读，超过 10 条时删最旧的。这是工作原则，不是某个项目的记忆。

1. **证据必须当次实时联网检索**：写进方案的任何数字/URL 必须来自本轮真实 general_search，带 URL+日期+原文；凭模型记忆的数标假设，不进对客稿。
2. **预算出处纪律**：客户写 "suggest by agency / TBD" 时，总预算必须是反推出来的（人群盘×Reach%×频次÷1000×CPM），附推导表，标 recommended，不拍整数。
3. **策略/工具解耦**：怎么想走 references/strategy-playbook.md（prompt），算数/出表走 scripts/（代码）。新能力先写 playbook，犯两次错再成代码。
4. **地基字段没写死必须先问，不许自己猜**：市场/国家、预算口径（币种/含税不含税/总预算还是媒介净预算）、KPI 术语定义（如 3+4、A+1）、落地页 URL、素材是否客户供给——这些字段 brief 没明写时，**第一步就用一句话问用户**，不许从价格数字、竞品名单、平台建议反推一个市场/口径然后开搜。价格数字不是唯一解（同一价格段在目标市场/孟加拉/巴基斯坦都可能命中），猜错等于把整轮证据检索和预算矩阵作废。追问时不要把自己的猜测包装成弹窗选项第一项，直接开放式问。
5. **Excel 汇总列直接填数值，不写公式**：openpyxl 写 `=SUM(...)` 公式不会缓存计算值，用户用 Excel 外查看器或首次打开未触发计算时，J 列 Line Total 会显示空白/0。交付前用 `openpyxl.load_workbook(path, data_only=True)` 回读关键汇总列，发现 None 就改成预计算数值（明细行=日预算×天数，owner=Σ明细，阶段=Σowner）。这条已在 某手机客户 目标市场单翻过车（2026-09），不要再犯。
6. **交付前自检数字守恒**：生成 Excel 后必须用脚本回读三级汇总（明细→owner→阶段→总预算），加总必须等于总预算（容差 ≤0.5%），并确认 J/K 列都有数值而非公式字符串。发现对不上立刻修，不许"Excel 打开就会算"交出去。
7. **list_row 类 Sheet 写循环时所有字段从循环变量取**：Strategy/Audience/TO-DO 等多行表在 Python 里用列表推导式生成 rows 时，**每一行的每个字段都必须从循环变量取**，不能把上一行的值硬编码进字典字面量。某手机客户 目标市场单就翻过这个车：三行 Strategy 都写成 Pre-Buzz（period/phase/budget_pct 硬编码），只有 actions 跟了循环，导致合计 105%。写完逐 sheet 抽查：行数 = 预期、每行关键字段值不重复。
8. **多阶段/多分组行用配色区分**：Strategy 阶段表、Audience 人群表等多行同结构表，不同行（不同阶段/不同分组）必须用不同浅色背景区分，不能全用同一底色——客户看图要一眼区分时期。配色与 ④ MediaPlan 树状表阶段色系对齐：Pre-Buzz 浅蓝（DDEBF7）/ Launch 浅橙（FCE4D6）/ Sustain 浅绿（E2EFDA）；人群分组同理按 T1/T2/T3 分色。某手机客户 目标市场单三行 Strategy 全黄被客户指出后补色（2026-09）。
