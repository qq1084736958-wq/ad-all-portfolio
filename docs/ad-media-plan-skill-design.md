# ad-media-plan Skill 设计方案：数字广告投放策略生成

> 部分内容由豆包生成



# 01 Skill 定位与命名

**建议名称：**ad-media-plan（数字广告投放策略生成）

**一句话描述：**输入客户 brief（图片/文档/文本），自动输出完整的数字广告投放策略飞书文档 + 投放排期飞书表格，覆盖受众分层、平台策略、预算分配、创意策略、排期规划、KPI 体系与风险预案。

**触发条件：**用户提到"出投放策略""做媒介计划""广告排期""media plan""投放方案"等，且提供了或需要基于产品 brief 来做。

# 02 涵盖的内容模块（9 大输出章节）

| 模块 | 输出内容 | 推导逻辑 |
|-|-|-|
| **项目背景与目标** | 产品/定价/预算/卖点/节点/竞品汇总；量化目标 | 直接从 brief 提取，目标做合理诠释 |
| **受众分层策略** | T1/T2/T3 三层定义、痛点、定向方式、预算占比 | brief 已给人群定义 → 补充定向逻辑和分配 |
| **卖点与传播主张** | 主 Slogan + 卖点→场景→话术映射表 | 参数翻译为用户利益，匹配人群场景 |
| **平台投放策略** | 各平台预算占比、链路角色、广告产品组合、定向逻辑 | 严格遵循客户指定优先级，按平台特性分工 |
| **预算分配** | 按平台分配 + 按阶段分配，双维度矩阵 | 平台优先级定占比，节点定阶段权重 |
| **创意策略** | 素材矩阵（类型/信息/平台/数量）+ 测试机制 | 卖点决定素材类型，平台决定规格 |
| **投放排期** | 按周/阶段拆解各平台动作 + 关键节点标注 | 预售/开售/首销月节点驱动分段 |
| **KPI 体系** | 认知/兴趣/转化三层指标 + 目标值 + 数据来源 | brief 目标拆解到可执行指标 |
| **风险预案** | 风险类型 + 影响等级 + 应对措施 | 行业常见风险 + 本项目特定风险 |

# 04 核心逻辑（5 条硬约束）

1. **Brief 是唯一事实源** — 产品名、价格、预算、卖点、人群、节点全部从 brief 提取，不编造、不替换。策略推导中补充的内容（如定向方式、话术、KPI目标值）必须标注为"建议"。
2. **平台优先级不可逾越** — 客户写 Meta > TT > YTB，预算占比就必须按这个顺序递减，不能因为"TikTok效果好"就反过来。这是客户的硬约束。
3. **预算守恒自动校验** — 平台分配之和 = 100%，阶段分配之和 = 100%，平台×阶段交叉表之和 = 总预算。生成后用 calculator 或脚本回算，不等就报错修正。
4. **节点驱动排期分段** — brief 中的"线上预售 7.9""线下预售 7.14""开售 7.28""首销月 7.28-8.27"是排期的骨架，所有阶段划分和预算权重都围绕这些节点。
5. **动作-预算-KPI 闭环** — 每个投放动作必须对应一笔预算和一个可衡量的 KPI，不允许出现"做了但不知道花多少钱、达到什么效果"的空动作。

# 05 执行流程（6 步）

| 步骤 | 阶段 | 具体动作 |
|-|-|-|
| **Step 1** | Brief 解析 | 读取图片/文档/文本 → 提取结构化字段（产品、预算、卖点、受众、目标、节点、竞品、平台）→ 缺失字段标记为"待补充"，不编造 |
| **Step 2** | 情报补全（可选） | 搜索竞品近期营销动作 → 核实平台广告产品规则与规格 → 获取行业基准 CPM/CPC/CTR |
| **Step 3** | 策略推导（核心） | 受众分层引擎 → 定向方式 + 人群预算占比；平台策略引擎 → 各平台角色 + 广告产品组合；卖点翻译引擎 → 主信息 + 场景话术映射；预算分配引擎 → 平台×阶段矩阵（守恒校验）；KPI体系引擎 → 三层指标 + 目标值 + 监测频率 |
| **Step 4** | 排期生成 | 按关键节点划分阶段（预热/预售/爆发/持续）→ 每阶段各平台具体动作 → 每阶段预算金额 |
| **Step 5** | 产物生成 | 飞书文档：9 章节策略方案（XML 模板填充）；飞书表格：排期表 + 预算表 + KPI表（3 子表） |
| **Step 6** | 校验交付 | 预算守恒回算 → 表格数据回读验证 → 样式美化（表头/列宽/冻结/高亮关键节点）→ present_files 交付 |

# 07 与现有 Skill 的关系

这个 Skill 不是从零造轮子，而是**编排层**：

- 调用 **lark-doc** 做文档生成
- 调用 **sheet** 做表格生成
- 调用 **doubao-visualization** 做图表增强
- 自身核心价值在于**策略推导逻辑**（受众分层、平台分工、预算算法、排期节点对齐）和**模板化输出**

> **升级方向：**如果要进一步升级，可以加入历史投放数据学习（根据过往项目的 ROI 自动调整平台预算占比）、A/B 测试规划模块、达人/KOL 资源匹配模块。
